# IP Tray Monitor

Небольшое фоновое приложение для Windows на Rust: показывает **внешний (публичный) IP-адрес** в трее и сигналит, если он не совпадает с ожидаемым.

| Значок | Состояние |
|---|---|
| 🟢 зелёный | IP совпадает с целевым (или целевой не задан) |
| 🔴 красный | IP **не совпадает** с целевым + окно-предупреждение поверх всех окон |
| ⚪ серый | IP определить не удалось (нет сети / сервисы недоступны) |

- Наведите курсор на значок — во всплывающей подсказке будет текущий IP, статус и время последней проверки.
- Правая кнопка мыши — меню **Settings** / **Exit**. Левая кнопка — сразу открывает настройки.
- Автозапуск при входе в Windows включается при первом запуске (отключается в настройках).
- Повторная проверка происходит по таймеру и сразу при смене сети (Wi-Fi, VPN, кабель, выход из сна).

## Настройки

Окно **Settings**:

- **Target IP** — ожидаемый адрес. Можно указать несколько через запятую и/или подсети в CIDR: `203.0.113.10, 198.51.100.0/24`. Пустое поле — просто показывать IP без сравнения.
- **Check interval** — период проверки в секундах (10–86400, по умолчанию 60).
- **Start automatically with Windows** — автозапуск (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).
- **Show an alert window…** — при несовпадении всплывает окно-предупреждение (поверх всех окон, со звуком). Когда IP возвращается к правильному, окно закрывается само и показывается короткое уведомление.

Настройки хранятся в `%APPDATA%\IpTrayMonitor\config.json`:

```json
{
  "target_ip": "203.0.113.10",
  "check_interval_secs": 60,
  "notifications": true
}
```

Необязательное поле `"providers": ["https://..."]` позволяет задать свои сервисы определения IP (ответ — IP простым текстом). По умолчанию по очереди опрашиваются `api.ipify.org`, `checkip.amazonaws.com`, `ipv4.icanhazip.com`, `ipinfo.io/ip`.

## Сборка

Нужен [Rust](https://rustup.rs) (stable).

```powershell
cargo build --release
# результат: target\release\ip-tray-monitor.exe
```

Тесты логики сравнения IP и конфига запускаются на любой ОС: `cargo test`.

Кросс-компиляция из Linux: `rustup target add x86_64-pc-windows-gnu`, пакет `mingw-w64`, затем
`cargo build --release --target x86_64-pc-windows-gnu`.

## Устройство

```
src/
  main.rs    — запуск, единственный экземпляр, первый запуск
  app.rs     — значок в трее, меню, окно настроек, фоновая проверка
  net.rs     — запрос внешнего IP (несколько сервисов по очереди, TLS через Windows SChannel)
  target.rs  — разбор целевых адресов/подсетей и сравнение (с unit-тестами)
  config.rs  — чтение/запись config.json
  sys.rs     — WinAPI: mutex, автозапуск в реестре, NotifyAddrChange, TaskbarCreated
res/         — манифест (DPI, Common Controls v6), ресурсы, версия
assets/      — иконки
```

GUI — [native-windows-gui](https://github.com/gabdube/native-windows-gui), HTTP — `ureq` + `native-tls`. Готовый exe — один файл ~0,8 МБ без внешних зависимостей.
